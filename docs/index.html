📅 Come aggiungere a Google Calendar

  1. Clicca il pulsante Google Calendar del calendario che vuoi.
  2. Si apre Google Calendar con la finestra "Aggiungi calendario tramite URL".
  3. Clicca Aggiungi calendario. Le partite/gare appaiono in pochi minuti.
  4. Google sincronizza ogni 12-24 h. Per aggiornare subito: Impostazioni → [calendario] → Aggiorna.

🍎 Apple Calendar / Outlook

  1. Clicca Download oppure copia l'URL del file .ics.
  2. Apple: File → Nuovo abbonamento calendario → incolla URL.
    Outlook: Aggiungi calendario → Da Internet → incolla URL.
  3. Imposta la frequenza di aggiornamento a ogni giorno.
