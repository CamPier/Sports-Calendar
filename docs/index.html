Come aggiungerlo a Google Calendar

  1. Clicca il pulsante Google Calendar della lega che vuoi — oppure copia l'URL del file .ics.
  2. Si aprirà Google Calendar con la finestra "Aggiungi calendario tramite URL".
  3. Clicca Aggiungi calendario. Il calendario si popolerà automaticamente.
  4. Google Calendar sincronizza il feed ogni 12-24 ore. Per forzare l'aggiornamento usa Impostazioni → [Calendario] → Aggiorna.

Come aggiungerlo ad Apple Calendar / Outlook

  1. Copia l'URL del file .ics che vuoi.
  2. Apple Calendar: File → Nuovo abbonamento calendario → incolla l'URL.
    Outlook: Aggiungi calendario → Da Internet → incolla l'URL.
  3. Imposta la frequenza di aggiornamento a ogni ora o ogni giorno.
